# Projeto Banco de Dados

## Tema

Gerenciamento de Projetos

## Objetivo

Desenvolver um banco de dados para gerenciamento
de projetos corporativos, usuários, departamentos,
cargos e atividades.

## Público-alvo

Empresas que precisam organizar seus projetos
e equipes.

## Tecnologias

- PostgreSQL
- SQL
- GitHub
